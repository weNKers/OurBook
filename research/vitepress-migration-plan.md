# VitePress Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Migrate OurBook from VuePress 2 to VitePress while preserving current public URLs, content, search, SEO metadata, comments, and GitHub Pages deployment.

**Architecture:** Keep `docs/` as the VitePress source root and make the production build the external seam. A focused site contract test will invoke `npm run build` and assert the generated site uses VitePress and retains its observable pages, URLs, metadata, static assets, search, comments, and sitemap. Existing content audits remain responsible for source integrity; their public commands are updated for the new content and public asset layout.

**Tech Stack:** Node.js 24, npm, VitePress 1.6.4, Vue, Node built-in test runner, GitHub Actions Pages.

**Spec:** [research/vitepress-migration.md](../vitepress-migration.md)

## Global Constraints

- Preserve root deployment with `base: '/'` and custom domain `www.wenkers.cn`.
- Preserve every current content URL, including directory URLs currently backed by `README.md`.
- Preserve 416 Markdown source pages and all existing audit commands.
- Preserve page descriptions, keywords and content type in search behavior and page metadata.
- Preserve the current `og:url` host, Open Graph metadata, sitemap exclusion for `/feedback/`, Cusdis comments, and last updated display; emit canonical URLs on the same host.
- Use stable VitePress `1.6.4` as the migration target unless the version check before installation establishes that the current stable v1 line has advanced.

## Review Focus

- A moved `README.md` page could change the directory URL; pin representative root, guide and school routes in the site contract test.
- A raw HTML or Markdown asset URL could bypass VitePress base handling; keep root deployment and check representative images and linked public files.
- SEO output could omit page-level descriptions or social metadata; assert metadata in generated HTML for home and a university article.
- Local search could lose searchable metadata or Chinese token behavior; check configured fields and run a browser search smoke check after integration.
- Client side navigation could leave Cusdis attached to the previous page; check the comments container identity and page id after navigating between pages.
