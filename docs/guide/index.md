# 快速上手

- PC端点击左侧菜单以进行文章浏览，移动端请点击左上角的菜单图标以获取目录。

- 使用顶部的本地搜索查找学校、专业、学院和关键词。搜索会匹配文章正文及标题、描述等信息；可以输入多个关键词，结果按相关度排列。

- 每篇文章底部都有邮件反馈入口，可以直接反馈该页面的问题；也可以从顶部导航进入[意见反馈](/feedback/)填写完整表单。

- 如果发现内容或排版问题，可以点击页面底部的**帮助我们改善此页面**直接编辑，也可以通过[反馈页面](/feedback/)联系我们。

- 大学的基础介绍均来自[维基百科中文](https://zh.wikipedia.org/wiki/Wikipedia:%E9%A6%96%E9%A1%B5)，如需了解更多请自行检索相关学校资料。
