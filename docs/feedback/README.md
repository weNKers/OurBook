## 项目更新日志

### 2026-08 · VuePress 2 重构与静态化升级

本次完成了项目的一轮整体重构和发布流程升级，当前站点可以在没有独立服务器的情况下，通过 GitHub Pages 持续发布。

#### 技术架构

- 从旧版 VuePress 迁移到 VuePress 2 + Vite
- 使用 VuePress 默认主题，保留原有紫色品牌色
- 运行环境统一为 Node.js 24、npm 11
- 站点继续保持纯静态托管，不需要数据库或后端服务器
- Contributors 统一显示为 `Liyuk`

#### 搜索与浏览体验

- 使用 VuePress SlimSearch 本地搜索
- 支持正文、描述、关键词和内容类型检索
- 优化中文页面的搜索结果展示
- 保留快捷键 `/` 和 `S`
- 完成桌面端和移动端搜索入口验收

#### 内容与资源管理

- 为 416 篇 Markdown 内容统一整理 frontmatter
- 增加内容类型、描述、关键词等元数据
- 新增内部链接自动审计
- 新增本地资源和远程图片检查
- 当前检测到的 37 个远程图片全部可访问
- 图片默认使用异步解码和懒加载

#### 评论区

- 接入 Cusdis 免费评论服务
- 通知邮箱设置为项目维护邮箱
- 普通访客无需 GitHub 账号即可留言
- 评论提交后需要审核才会公开
- 修复 VuePress SPA 页面切换时评论 iframe 重复加载的问题
- 多次切换页面时始终只保留一个评论实例
- 评论区支持高度调整和加载失败提示

#### 部署与测试

- 发布流程迁移到 GitHub Actions
- 推送 `master` 后自动构建并发布 GitHub Pages
- 自动执行内容、资源、图片和内部链接检查
- 构建成功渲染 417 个页面
- 完成多页面 SPA 切换验收
- 完成 390px 移动端布局验收
- 完成评论表单、搜索入口和横向溢出检查
